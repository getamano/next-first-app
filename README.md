# My First Next.js App

In this project, I explored the core features of **Next.js** and built a simple application to put them into practice.

### Key Learnings:

- **Routing** with the App Router
- **Layouts** for consistent page structure
- **Loading states** to handle async rendering
- **Fetching data** from APIs
- **Creating custom APIs** within the app
- Understanding the two types of components:

  - **Server Components** (default in Next.js)
  - **Client Components** (for interactive UI)

- use rto define and use .env configurations
